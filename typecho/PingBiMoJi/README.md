# PingBiMoJi - 笔墨迹主动推送插件

发布文章时自动通知笔墨迹抓取，实现文章实时同步。

## 功能特性

- 发布文章后自动向笔墨迹发送 Ping 通知
- 支持仅新发布时推送，或发布和更新时都推送
- 支持记录推送日志，便于排查失败原因
- 支持调试模式，显示更完整的日志内容
- 支持博主地图位置同步
- 兼容 PHP 8.1 与新版 Typecho 后台

## 安装方法

1. 将 `PingBiMoJi` 文件夹上传到 Typecho 的 `usr/plugins/` 目录
2. 登录 Typecho 后台，进入「控制台」→「插件」
3. 找到「笔墨迹主动推送插件」，点击「启用」
4. 点击「设置」进行配置

## 配置说明

| 配置项 | 说明 | 示例 |
|-------|------|------|
| 笔墨迹 Ping 接口地址 | 默认无需修改 | `https://blogscn.fun/blogs/api/ping` |
| 你的 RSS 地址 | **必填**，你在笔墨迹登记的 RSS 地址 | `https://yourblog.com/feed/` |
| 验证 Token | 可选，如果笔墨迹分配了 Token | 留空即可 |
| 是否启用推送 | 启用/禁用推送功能 | 启用 |
| 推送时机 | 仅新发布 或 发布和更新时 | 仅新发布时 |
| 调试模式 | 开启后记录详细日志 | 关闭 |

## 使用方法

配置完成后，每次发布新文章时，插件会自动：

1. 向笔墨迹发送 Ping 通知
2. 笔墨迹收到通知后立即抓取你的 RSS
3. 新文章会在几秒内出现在笔墨迹

## 频率限制

- 每个博客每小时最多 Ping 5 次
- 超过限制会返回 429 错误

## 常见问题

### Q: 推送失败怎么办？

1. 检查 RSS 地址是否正确
2. 确认你的博客已在笔墨迹登记
3. 开启调试模式查看详细错误

### Q: 升级到 PHP 8.1 或新版 Typecho 后后台报错怎么办？

如果出现类似 `Constant __TYPECHO_ADMIN__ already defined` 的警告，请使用最新版插件文件。新版本已经调整后台日志页的加载方式，避免重复引入 Typecho 后台公共文件。

### Q: 为什么文章没有同步？

1. 检查文章是否已发布（草稿不会触发）
2. 检查推送时机设置
3. 查看插件设置页面的「最近推送日志」

### Q: 支持哪些 Typecho 版本？

支持 Typecho 1.2.0 及以上版本，推荐搭配 PHP 7.4 至 PHP 8.1 使用。

### Q: 后台样式错乱怎么办？

最新版已经为日志页自定义样式增加独立的 `xiangming-` 前缀，并限制内容最大宽度，尽量避免被后台或主题的全局样式影响。如果你仍在使用旧版文件，请直接覆盖升级。
